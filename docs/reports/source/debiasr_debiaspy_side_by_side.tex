likelihood at identical R coefficient draws, then sends those draws through
the actual R and Python prediction helpers. It checks both observed predictions
and the zero-bias counterfactual. Joint log priors agree within
$1.5\times10^{-13}$, log likelihoods within $5.8\times10^{-11}$ and predicted
rates within $1.6\times10^{-13}$ relative error. This rules out the checked
prior parameters, centring, link and counterfactual prediction paths as the
explanation for this discrepancy.
